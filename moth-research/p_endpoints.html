Endpoints

Base URL https://api.mothquantum.com/api/v1, bearer auth on every call (Authentication). Full schemas, try-it and the always-current spec live in the API reference; the machine-readable contract is /openapi.json. Per-engine calls are in Engines.

Generated from moth-api v0.41.0 on 2026-09-25 · 56 operations. The API reference is always current.

auth​

EndpointWhat it does
GET/meCurrent user. Returns the identity of the authenticated caller.

keys​

EndpointWhat it does
GET/keysList API keys. Lists API keys owned by the caller.
POST/keysCreate an API key. Mints a new API key owned by the caller.
DELETE/keys/{keyID}Revoke an API key. Permanently revokes a key owned by the caller.
PATCH/keys/{keyID}Enable or disable an API key. Updates a key owned by the caller.

engines​

EndpointWhat it does
GET/enginesList engines. Lists visible engines by ID ascending.
POST/enginesCreate engine. Creates a personal engine owned by the caller, or an organization engine when organization_id is provided and creation policy permits it.
GET/engines/{engineID}Get engine. Returns the full definition of a visible engine, including its params schema.
PATCH/engines/{engineID}Update engine. Partially updates an engine; omitted fields keep their current value.
POST/engines/{engineID}/transferTransfer a personal engine to an organization. Requires a Supabase access JWT and a current active account.

jobs​

EndpointWhat it does
POST/engines/{engineID}/processSubmit a job. Validates params against the engine's schema, records the job, and starts the workflow.
GET/jobsList jobs. Lists the caller's jobs newest first with the status last persisted to job history; poll get-job-status for live workflow state.
GET/jobs/{jobID}Get a job. Returns the recorded job row without querying the execution backend; poll get-job-status for live workflow state.
GET/jobs/{jobID}/resultGet a job's result. Returns the completed job's outputs: one entry per declared output_files slot, each with a presigned download URL (every output is also recorded as a kind=output asset), or the inline JSON result for engines that produce no files.
GET/jobs/{jobID}/statusGet job status. Returns the live status of a job with view access.

assets​

EndpointWhat it does
GET/assetsList assets. Lists the caller's assets newest first.
POST/assetsCreate an asset. Records a pending asset and returns a presigned upload URL.
DELETE/assets/{assetID}Delete an asset. Requires delete access.
GET/assets/{assetID}Get an asset. Returns metadata for an asset with view access.
POST/assets/{assetID}/completeComplete an upload. Owner-only operation.
GET/assets/{assetID}/downloadGet a download URL. Returns a presigned URL that serves the file bytes with the asset's filename and content type.
GET/me/storageCurrent storage usage and quota. Returns the caller's stored bytes by kind and the storage quotas enforced for them.

showcases​

EndpointWhat it does
GET/showcasesList showcases. Lists visible showcases by creation time descending then ID ascending.
POST/showcasesCreate showcase. Creates a link to a deployed app built with a visible engine.
DELETE/showcases/{showcaseID}Delete showcase. Deletes a showcase with delete access.
GET/showcases/{showcaseID}Get showcase. Returns a visible showcase.
PATCH/showcases/{showcaseID}Update showcase. Partially updates a showcase with edit access; omitted fields keep their current value.
POST/showcases/{showcaseID}/transferTransfer a personal showcase to an organization. Requires a Supabase access JWT and a current active account.
